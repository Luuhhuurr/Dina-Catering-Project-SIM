Keterangan rancangan

Tujuan layar

Menjaga agar hanya pemilik usaha yang dapat masuk dan melihat data usaha.

Komponen

  • Kartu login di tengah layar, tanpa sidebar dan tanpa topbar.
  • Kolom username.
  • Kolom password (disembunyikan, type="password").
  • Tombol Masuk.
  • Banner pesan galat, muncul hanya ketika login gagal.

Perilaku

  • Berhasil → 303 ke / (Dashboard).
  • Gagal → pesan "Username atau password salah", field username tetap terisi.
  • Sudah punya sesi → 303 ke /.
  • Password diperiksa terhadap hash bcrypt; cookie sesi bertanda tangan HMAC-SHA256 berlaku 12 jam.

Catatan

Akun bawaan saat instalasi: admin / admin123. Password di-hash saat proses seed, bukan ditulis di dalam kode.
